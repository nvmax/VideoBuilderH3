H3 Studio now has Overlays on the timeline (grain, vignette, text, lyric captions, a LUT and dust or light leak clips), a GPU choice for the local LLM, and a Builder that works over a LAN address.

- **Overlays.** The Post Process tab is now **Overlays**. It lays film grain, a vignette, text, a LUT and clips such as dust, smoke and light leaks over the finished video. Each one is a block on the new OVERLAYS lane of the timeline: drag it, drag its edges to trim or extend it, split it at the playhead, or select it and press Delete. **Subtle film** adds grain and a vignette in one click. **Add lyric captions** makes one text overlay for each lyric line, timed to the words when the project has word timing, and **Remove captions** takes them all off at once. The player shows them live, **Check this frame** renders the exact picture, and Render All, Export and every stitch an agent makes draw them in the same pass.
- **Overlay library.** Clips you download (the free sections of FX Elements, Pexels or Pixabay) live in `ComfyUI\models\overlay`. Change the folder in Settings, "Overlay library folder". **Import clip...** and **Import folder...** copy them in and make a still and a short preview. ProRes and MP4 work, RED RAW does not. Six free fonts come with the app for the text.
- **Agents.** `GET /overlay-library`, `GET` and `PUT /projects/{pid}/overlay-layers`, and `POST` to `.../overlay-layers/add`, `/lyric_captions` and `/media`, with six new MCP tools. A stitch reports an `overlay_layers` section, and `overlay_layers: false` leaves the overlays out.
- **GPU choice for Gemma Local and Qwen Local.** The LLM Runner has a GPU select. Automatic keeps today's behavior, and a number puts the whole model on that GPU so the other one stays free for ComfyUI's renders. Each card is listed with its name, memory and the number Windows uses for it, because ComfyUI's numbers can differ. A card ComfyUI cannot see is listed with the reason. This needs the newer comfyui-vrgamedevgirl pack in ComfyUI (Beta2.0, pull request 300) and a ComfyUI restart. On Windows ComfyUI limits itself to one GPU unless it is started with `--default-device N`, and the dialog says so.
- **The Builder over a LAN address.** With `api_bind` set to a non-loopback address, the page served from the computer's LAN address can now save, edit and render. It was refused before (from oneevil). The API still has no password, so use it only on a network you trust.
- **Pop-out windows.** The LLM Prompting pop-out no longer leaves an empty window behind when it closes or is opened again.

Installed 0.1.5 offers this update itself: Menu, Check for Updates. Nothing installs without your click, or while a job is running. New installs: download `H3-Studio_0.1.6_x64-setup.exe` for Windows, or `H3-Studio_0.1.6_amd64.AppImage` or `H3-Studio_0.1.6_amd64.deb` for Linux below.
