H3 Studio 0.1.16 adds Server RefMods: share your RefMods with other people and add the ones they shared.

- **Server RefMods.** The RefMods Viewer has a My RefMods / Server RefMods switch. Server RefMods lists what other people shared, sorted by type like your own, and Add to my library saves one next to your RefMods. Share to server sends one of yours, and Report flags one that should not be there. You sign in once with GitHub or Discord, and the sign-in opens in your normal browser. No secret is built into the app. The first RefMods of a new account wait for the owner's approval and show "Waiting for approval" until then. The server is https://aidigitalcreations.com, and the Server settings button changes the address.

Installed 0.1.15 offers this update itself: Menu, Check for Updates. Nothing installs without your click, or while a job is running. New installs: download `H3-Studio_0.1.16_x64-setup.exe` for Windows, or `H3-Studio_0.1.16_amd64.AppImage` or `H3-Studio_0.1.16_amd64.deb` for Linux below.
