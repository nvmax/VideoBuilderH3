H3 Studio 0.1.27 keeps the Builder filling the whole app window and makes the Custom Nodes window work from the app.

- **Always full window.** The fullscreen button in the top right of the Builder is gone. The Builder fills the app window and no longer drops into a floating panel inside it.
- **Custom Nodes window.** It now asks the VRGDG node pack in your ComfyUI, so it knows whether ComfyUI-Manager is there, and Install and Install Missing Nodes work from the app (ComfyUI-Manager does the installing, then restart ComfyUI). Before, the window always said ComfyUI-Manager was not installed. When ComfyUI is not running or the pack is not installed in it, the window still lists what is installed and says why it cannot install.
- **MiniMax H3 latent upscaler built in.** ComfyUI 0.44.0 and newer has this upscaler itself, so the window shows the Comfyui_Minimax_h3_latent_Upscaler pack as Built in and no longer asks for it. Older ComfyUI still needs that pack.
- **Needs the matching pack update** for installing nodes from the app and for the built-in upscaler. Update the pack and restart ComfyUI.

Installed 0.1.26 offers this update itself: Menu, Check for Updates. Nothing installs without your click, or while a job is running. New installs: download `H3-Studio_0.1.27_x64-setup.exe` for Windows, or `H3-Studio_0.1.27_amd64.AppImage` or `H3-Studio_0.1.27_amd64.deb` for Linux below.
