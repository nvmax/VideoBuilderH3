H3 Studio 0.1.33 shows which models you already have: installed files keep their check mark, and files you do not have yet say Available in yellow instead of Missing in red.

- **Installed files stay ticked.** In the Models dialog an installed file used to have an empty, greyed-out box next to its Installed badge. It now keeps its tick (greyed out, it cannot be picked again), and a card whose files are all installed is ticked too. Install Selected still counts only the files that are left to download.
- **Available, not Missing.** These files come in many versions and nobody needs all of them, so a red Missing suggested something was wrong. A file that is not installed now says Available in yellow, on the MiniMax H3, Image Models, LLM Models and DMAD LoRA tabs. Files that need a Hugging Face login say Login needed in orange.

The pack has the same change since pack 10.0.10: update it in ComfyUI-Manager and refresh the browser page. No restart is needed.

Installed 0.1.32 offers this update itself: Menu, Check for Updates. Nothing installs without your click, or while a job is running. New installs: download `H3-Studio_0.1.33_x64-setup.exe` for Windows, or `H3-Studio_0.1.33_amd64.AppImage` or `H3-Studio_0.1.33_amd64.deb` for Linux below.
