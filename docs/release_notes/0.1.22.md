H3 Studio 0.1.22 adds DMAD sampling, sigma shift and a one-click installer for the DMAD LoRAs, plus better video quality for scene copies and clearer errors from hosted LLM services.

- **DMAD sampling.** Under the Standard / RefMod buttons there is now a Standard / DMAD row. Choosing DMAD fills in the settings it needs: the DMAD LoRA on pass 1, the refiner LoRA on pass 2 at 0.7, lcm / simple / 4 steps on pass 1, 3 steps at 0.2 denoise on pass 2, and a sigma shift of 12 video / 2 audio on pass 1. It works with both pipelines in Single and 2 Pass. Pass 1 and pass 2 steps boxes sit in the DMAD row so you can raise the steps without opening Advanced Settings. Choosing Standard puts back the values DMAD replaced and keeps LoRAs you added in between. A scene locked to its own settings keeps its own choice. Setting `use_dmad` through the settings API does the same.
- **Sigma shift for every project.** Advanced Settings has a Sigma Shift section, off by default, with a video and an audio value per pass. It needs a ComfyUI that has the ModelSamplingMiniMaxH3 node and says so when it is missing. 2 Pass Advanced ignores it. `lcm` is now in the sampler lists.
- **Dmad Models.** Menu, Models, Download models has a new Dmad Models button between MiniMax H3 and Custom Nodes. Install puts the two DMAD LoRAs into the first `loras` folder ComfyUI reports, with progress and Cancel. It checks each file, never replaces one you already have, and the LoRA lists and the DMAD note refresh when a file is done.
- **Redecode from the API.** A scene render can take `render_phase: "redecode"`, which makes the scene's video again from its saved latent at a finer `crf`, with no sampling. Scenes rendered with built-in audio are refused. It needs the matching Video Builder pack update (the `VRGDG_MiniMaxH3LoadLatentFull` node) and a ComfyUI restart.
- **Scene video quality.** Scene copies, stitch re-encodes and transition clips use CRF 16, preset medium and AAC 256k, and are never coarser than the CRF the source file states.
- **Hosted LLM certificates.** Requests to hosted LLM services check the server against the Windows certificate store first and the built-in roots only if that check fails. This also works behind an HTTPS-inspection root that Windows trusts. A failure now says `TLS certificate validation failed for <host>`, and nothing is sent over a connection that could not be verified. `docs/LLM_API_TLS.md` lists the steps to take.

Installed 0.1.21 offers this update itself: Menu, Check for Updates. Nothing installs without your click, or while a job is running. New installs: download `H3-Studio_0.1.22_x64-setup.exe` for Windows, or `H3-Studio_0.1.22_amd64.AppImage` or `H3-Studio_0.1.22_amd64.deb` for Linux below.
