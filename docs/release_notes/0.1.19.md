H3 Studio 0.1.19 makes the Builder load and save faster when H3 Studio is reached over a slow connection, for example through a reverse proxy to a computer at home.

- **Text replies are compressed.** The screens and JSON replies are sent gzipped to a browser that asks for it. Video, audio, fonts, images, zip and binary files and the event streams are sent as they are, so playback and seeking still work.
- **Large saves are uploaded compressed.** The Builder gzips request bodies of 256 KB or more, such as a project save, and the server unpacks them. The size limit applies to the unpacked size.
- On a slow link the contributor measured loading all 188 modules without cache in about 1.4 s instead of 8 s, and a 3.4 MB JSON save in 0.7 s instead of 8.7 s. On the same computer you will not notice a difference.

Installed 0.1.18 offers this update itself: Menu, Check for Updates. Nothing installs without your click, or while a job is running. New installs: download `H3-Studio_0.1.19_x64-setup.exe` for Windows, or `H3-Studio_0.1.19_amd64.AppImage` or `H3-Studio_0.1.19_amd64.deb` for Linux below.
