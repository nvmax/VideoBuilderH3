H3 Studio 0.1.24 brings in the latest Video Builder pack changes: a Gemma vision model, storyboards that start from a story idea alone, and Whisper that stays loaded while scenes are timed back to back.

- **Gemma vision model.** The LLM Runner has a new vision model setting for Gemma Local. Steps that look at a picture, such as describing a reference image, use it, and text steps keep the main model. It is the main model unless you choose another, and if ComfyUI no longer lists the chosen file the main model is used instead of failing the step. `GET /llm/active` now lists `model` and `vision_model` for Gemma Local.
- **Story first.** A story idea is enough to create the story brief. You no longer need lyrics or scene notes first. LM Extract for locations starts from the saved story idea, arc and brief when there is one and uses lyrics and scenes as extra context. Without supplied locations, the story and beat prompts invent a small set of reusable settings, so no reference images are required.
- **Whisper loads once.** Timing scenes back to back keeps the Whisper model loaded between scenes instead of reloading it for each one. Clear Memory now asks the pack inside ComfyUI to free Whisper and the GGUF models along with ComfyUI's own models.
- **Builder front end.** The Video Builder window is updated from the pack (203 files).
- **Needs the matching pack update.** Update the pack and restart ComfyUI to get all three changes. With an older pack, Clear Memory falls back to ComfyUI's plain free call.

Installed 0.1.23 offers this update itself: Menu, Check for Updates. Nothing installs without your click, or while a job is running. New installs: download `H3-Studio_0.1.24_x64-setup.exe` for Windows, or `H3-Studio_0.1.24_amd64.AppImage` or `H3-Studio_0.1.24_amd64.deb` for Linux below.
