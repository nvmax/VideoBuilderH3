H3 Studio 0.1.25 fixes Draft Story on the built-in Gemma and brings in the latest Video Builder pack changes: the Thumbnail intro, MOSS-Image downloads and new model choices.

- **Draft Story on the built-in Gemma.** The Gemma node in ComfyUI cut every reply to one paragraph, so Draft Story came back as a single "Act 1" with one paragraph. Steps that need several paragraphs (the story, acts, beats, scene prompts, dialogue, speech and the H3 video prompts) now ask the node for the whole reply. LM Studio, a custom server and the API runners were never affected.
- **Thumbnail intro.** A Thumbnail button in the middle of the toolbar. Pick the exact frame of the final video, write the title and the prompt (or let the LLM write it), and generate with Qwen Image Edit or NanoBanana. The history of tries is kept in the project. The Overlay and API image engines of the pack are not in this app yet.
- **Models.** The MOSS-Image Edit LoRA download installs the file as `moss_image_edit_lora.safetensors`. MiniMax H3 diffusion models now offer the official collection and the Singularity models. The custom nodes list includes the Euler Flow Matching scheduler node.
- **Builder front end.** The Video Builder window is updated from the pack (211 files), including Auto Build inputs that are remembered per project and bypass buttons for MiniMax reference changes in the Render All error window.
- **Needs the matching pack update.** Update the pack and restart ComfyUI for the Draft Story fix. With an older pack the app says so and asks you to update it, instead of cutting the reply.

Installed 0.1.24 offers this update itself: Menu, Check for Updates. Nothing installs without your click, or while a job is running. New installs: download `H3-Studio_0.1.25_x64-setup.exe` for Windows, or `H3-Studio_0.1.25_amd64.AppImage` or `H3-Studio_0.1.25_amd64.deb` for Linux below.
