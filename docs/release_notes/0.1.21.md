H3 Studio 0.1.21 brings in the newest work from the Video Builder pack: Seedance video through API Nodes, rendering a draft and finishing it from the API, and timing a singing scene's words before its prompt is written.

- **API Nodes video engine (Seedance 2.5).** In Menu, Builder Settings, Project Video Engine (or with the engine badge) a project can use API Nodes instead of MiniMax H3. Each scene then renders with ComfyUI's Seedance 2.5 Reference to Video node from the scene's Reference Builder pictures and optional video and audio references. Project or custom scene audio can guide the singing. Menu, Prompt Options, Convert All to Seedance Prompts turns existing prompts into Seedance prompts after saving a backup of them. It needs a ComfyUI with API nodes and a ComfyUI API key whose account has credits. Save the key in Menu, App Settings, ComfyUI API key. It stays on your computer and the Builder page never receives it.
- **Draft and finish from the API.** The scene render takes `render_phase`: `draft` renders pass 1 only and saves it, `finalize` runs pass 2 from that draft, and `full` (the default) does both. A draft that was made with a Turbo LoRA a newer release has replaced now finishes with the installed one.
- **Words are timed before a multi-shot prompt is written.** Writing the MiniMax prompts of a singing scene with several shots first times its words with Stable-ts on the scene's own audio, so each shot gets the words sung during it. The scene needs a mapped singer and the project or custom scene audio. This job now takes the GPU turn, so it waits for a render in progress.
- **Prompt wording.** The shot instructions ask for the readable supporting faces in every shot and give silent people their own reactions. A style that already ends in "music video" is no longer repeated in the opening line.
- **From the pack.** The Seedance controls show only in API mode, and the duplicate transcription button is gone from Prompt Options.

Installed 0.1.20 offers this update itself: Menu, Check for Updates. Nothing installs without your click, or while a job is running. New installs: download `H3-Studio_0.1.21_x64-setup.exe` for Windows, or `H3-Studio_0.1.21_amd64.AppImage` or `H3-Studio_0.1.21_amd64.deb` for Linux below.
