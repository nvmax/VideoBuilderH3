An AI agent can now build a whole music video in Story Mode, from the story to the prompts, through the built-in MCP server.

- **Story Mode steps for agents.** The Story Builder's steps (story book, places, acts, scene plan, beats) run as jobs on the LLM set in App Settings. An agent can also write every layer itself, so a story can be built with no LLM running: it saves the book, the setting looks, the acts and the scene plan, then maps each scene to its place card without asking a model. Saving a plan sets each scene's performance and cast and turns scenes that continue the one before into masked continuations.
- **RefMod cards.** A character or location card can render from a saved RefMod, and a new tool makes a RefMod from pictures.
- **Scenes without the singer.** A new tool splits the song into stems and writes the track without vocals, so a scene where the singer is off screen can render against it.
- **Bulk edits that say what is wrong.** A bad bulk edit is refused with the reason instead of applying nothing, and it takes scene numbers. Saving a location card keeps the fields you did not send.
- **An agent's edits survive an open Builder window.** The window's next autosave is refused instead of overwriting what the agent saved. Reload the project after a long run of agent edits.
- **Prompt writers use your LLM setting.** Concepts, motion notes, enhance and edit now use the LLM chosen in App Settings.
- **The app lists what it can do.** The health and meta answers carry a features block, so an agent plans with it.

Installed 0.1.3 offers this update itself: Menu, Check for Updates. Nothing installs without your click, or while a job is running. New installs: download `H3-Studio_0.1.4_x64-setup.exe` below.
