H3 Studio 0.1.31 looks for updates every few hours, so an app that stays open for days still hears about a new version.

- **Periodic update check.** The app used to look for a new version once, a few seconds after it started. It now looks again every 4 hours while it is open. A new version shows the same "Version X is available" note as before, with View update and Later. Later brings the note back at the next check, and Skip this version silences that version for good. A check is skipped while the Updates window or the note is already open. The "Look for updates when the app starts" checkbox in the Updates window is now "Look for updates when the app starts and every few hours", and turning it off stops both. It takes effect at once, with no restart.

Nothing installs without your click, or while a job is running. The check reads one public file on GitHub and sends nothing about you or your projects.

No pack update is needed. Installed 0.1.30 offers this update itself: Menu, Check for Updates. New installs: download `H3-Studio_0.1.31_x64-setup.exe` for Windows, or `H3-Studio_0.1.31_amd64.AppImage` or `H3-Studio_0.1.31_amd64.deb` for Linux below.
