H3 Studio 0.1.30 makes speaking scenes write speech instead of singing, makes the bulk scene patch save scene cards properly, and fixes Krea 2 pictures without the Z-Image enhance pass on ComfyUI installs that lack its nodes.

- **Speaking scenes speak.** The prompt writer asked every scene to sing, even in a Speaking project: the task said the character "sings <d>...</d> in sync with <Audio 1>" and the LLM was told the scene was a song. A speaking scene now gets the Video Builder's speaking task. Only the assigned speakers talk, everyone else listens with a closed mouth, and the exact lines go in `<d>` tags in the order they are spoken. A shot that still says "sings" comes out as "says", and with built-in audio nothing mentions `<Audio 1>`. Singing scenes are written exactly as before.
- **Bulk scene patch saves scene cards.** `POST /scenes/bulk` with `op: patch` copied the fields onto the scene as they were sent. `speaker_assignments` ended up under the wrong key, and `subject_ids` and `location_id` never reached the Reference Builder maps. It now saves card fields the way `PATCH /scenes/{sid}` does, and a bad value fails the whole batch with a 400 and saves nothing. Other fields are copied as before. This is the route behind the `scenes_bulk_edit` agent tool.
- **Krea 2 without the enhance pass.** With `use_zimage_enhance` off, the graph still held the whole Z-Image branch. ComfyUI refuses a prompt that names a node class it does not have even when the node is unused, so the picture failed with `missing_node_type` on installs without that branch's scheduler node. The unused branch is now left out of the graph.

These three come from pack pull request 318, whose author found them building a dialogue film through the agent API. The pack has not merged it yet, so the app carries the fixes first. The built-in Gemma problem in that pull request does not exist in the app: it already uses the first Gemma model ComfyUI lists when none is saved.

No pack update is needed. Installed 0.1.29 offers this update itself: Menu, Check for Updates. Nothing installs without your click, or while a job is running. New installs: download `H3-Studio_0.1.30_x64-setup.exe` for Windows, or `H3-Studio_0.1.30_amd64.AppImage` or `H3-Studio_0.1.30_amd64.deb` for Linux below.
