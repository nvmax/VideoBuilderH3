First public release of VRGDG H3 Studio, the desktop app for making MiniMax H3 music videos with ComfyUI.

- The Video Builder of the comfyui-vrgamedevgirl node pack (Beta2.0, including Scene Defaults and the Theatrical presets) as a standalone Windows app: songs, lyrics, scenes, references, MiniMax H3 renders, post processing and the final video.
- An agent API and a built-in MCP server, so Claude, Codex, Cursor, LM Studio and other agents can work in the same projects. Menu, MCP Setup shows how to connect each one.
- Internal beat calibration from the project's own audio.
- Updates itself from this page: Menu, Check for Updates, or a note a few seconds after the app starts. Nothing installs without your click.

Download `H3-Studio_0.1.0_x64-setup.exe` below and run it. It installs for your user and needs no administrator rights. Windows SmartScreen may warn about an unsigned installer: choose More info, then Run anyway. ComfyUI must run on the same computer with the node packs the setup screen lists. ffmpeg is included.

To build it yourself, see the README.
