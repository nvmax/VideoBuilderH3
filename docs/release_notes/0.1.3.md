An AI agent can now find a scene the way you say it: "scene 11".

- **Scenes by number.** Every tool an agent uses takes the scene's number on the timeline (the one the Builder shows) as well as its id. "Show me the prompt for scene 11" no longer needs the agent to look through the scene list. The agent instructions and each tool's description say so, and a scene that does not exist says how many scenes the project has.
- **Speaking mode.** The scene audio settings and the dialogue tools also take a scene number now. They only took ids before.

Installed 0.1.2 offers this update itself: Menu, Check for Updates. Nothing installs without your click, or while a job is running. New installs: download `H3-Studio_0.1.3_x64-setup.exe` below.
