H3 Studio 0.1.8 fixes three problems in RefMods Studio and the Builder, and lifts the 2 MB limit on uploads.

- **Pictures over 2 MB in RefMods Studio.** A picture larger than 2 MB failed to upload ("Error parsing multipart/form-data request"), so Describe from images and Create RefMod stayed off. Uploads now take up to 64 MB.
- **Clothing, Object, Prop, Vehicle and Creature RefMods.** Creating a Clothing (women), Clothing (men), Object, Prop, Vehicle or Creature RefMod failed because ComfyUI refused the type the Studio sent. ComfyUI now gets the nearest type it knows, and the RefMod is saved with its Studio type, so RefMods Viewer and the card pickers list it where it belongs.
- **Pictures are kept by the browser.** A RefMod preview is checked with the browser and sent again only when it changed. The Storyboard, the scene review and the Reference Builder keep one address per picture, so a redraw no longer downloads every picture in full. This helps most when you use the app from another computer.
- **No 2 MB limit on other uploads.** A scene or reference picture, a song sent to the agent API (`PUT /projects/{pid}/audio`) and a LUT larger than 2 MB were refused. Every route now takes up to 256 MB.

Thanks to @oneevil for the first three.
