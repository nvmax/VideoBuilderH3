H3 Studio 0.1.28 fixes Snap, stops 2 Pass renders from failing at the last node without nvidia-vfx, installs the MOSS-Image 8-step Turbo LoRA under the right name, and shows the name of the LLM you picked.

- **Snap works.** "Snap to beats" for every scene (what the song pipeline asks for) moved nothing and still said it had snapped. Every scene boundary within 0.14 s of a beat now moves onto it, scenes with a locked video stay where they are, and an unknown scope is refused instead of ignored. The answer says how many scenes moved.
- **2 Pass without nvidia-vfx.** The final resize is NVIDIA RTX Video Super Resolution, which needs the optional `nvidia-vfx` library. Without it the render used to run for its whole length and then fail at the last node. The app now asks the VRGDG node pack in ComfyUI whether the library is installed and resizes with `lanczos` instead when it is not. If the pack cannot answer, the graph is left as it was.
- **nvidia-vfx card.** The Custom Nodes window has a card that installs the library with pip from NVIDIA's index (about 800 MB), through the pack in ComfyUI. Install Missing Nodes leaves it alone.
- **MOSS-Image LoRAs.** The 8-step Turbo LoRA button now installs the file itself, like the Edit LoRA button, and saves it as `moss_image_sft_8_steps_dmd_lora.safetensors` instead of `lora.safetensors`, so there is nothing to rename. The Edit LoRA button is now just labelled "Edit LoRA".
- **The LLM you picked, by name.** Labels, tooltips, placeholders and messages in the Builder say LM Studio, LLM API, Qwen Local or Custom Server when that is the runner, instead of always saying Gemma. Gemma Local keeps its wording.
- **Needs the matching pack update** (10.0.7) for the nvidia-vfx card and check, and for the new reference prompt route. Update the pack and restart ComfyUI. With an older pack the render is built as before.

Installed 0.1.27 offers this update itself: Menu, Check for Updates. Nothing installs without your click, or while a job is running. New installs: download `H3-Studio_0.1.28_x64-setup.exe` for Windows, or `H3-Studio_0.1.28_amd64.AppImage` or `H3-Studio_0.1.28_amd64.deb` for Linux below.
