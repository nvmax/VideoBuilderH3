H3 Studio 0.1.15 fixes agents (MCP and the API) failing to render scenes of a RefMod project.

- **RefMod scenes render for agents.** An agent that rendered a scene of a RefMod project stopped at "Scene 1: This scene needs at least one ordered Reference Builder image" before ComfyUI was reached, even though the Render button in the Builder worked. The agent's render looked for Reference Builder pictures, and a RefMod card has none (a video RefMod never does). A RefMod render now uses the RefMods mapped to the scene, as the Builder does, and no longer asks for pictures. It also no longer checks that a card's picture file exists. A scene with no RefMod mapped still says so, and the standard pipeline still asks for a picture.

Installed 0.1.14 offers this update itself: Menu, Check for Updates. Nothing installs without your click, or while a job is running. New installs: download `H3-Studio_0.1.15_x64-setup.exe` for Windows, or `H3-Studio_0.1.15_amd64.AppImage` or `H3-Studio_0.1.15_amd64.deb` for Linux below.
