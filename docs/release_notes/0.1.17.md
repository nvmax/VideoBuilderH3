H3 Studio 0.1.17 fixes two Builder problems: text boxes losing the cursor while stems split, and Custom Server pictures that were never saved.

- **Typing is no longer interrupted while stem tracks load.** After a transcription, the background stem split finished one scene at a time and redrew the timeline each time, which threw the cursor out of the lyric, director note and video note boxes. The redraw now waits until you leave the box, and the stem tracks appear then.
- **Custom Server reference pictures are saved in the project.** Generating a location or subject reference with the Custom Server said it was created, but the card stayed empty and nothing was written to the project. The picture is now saved in the project's reference folder and shows on its card.
- **Custom Server in Generate Missing Images.** Generate Missing Location Images and Generate Missing Subject Images (also opened from the Story Builder buttons) now offer the Custom Server, so you no longer open each location one by one.

Installed 0.1.16 offers this update itself: Menu, Check for Updates. Nothing installs without your click, or while a job is running. New installs: download `H3-Studio_0.1.17_x64-setup.exe` for Windows, or `H3-Studio_0.1.17_amd64.AppImage` or `H3-Studio_0.1.17_amd64.deb` for Linux below.
