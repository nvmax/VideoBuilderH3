H3 Studio 0.1.14 shows the name of the open project at the top of the Builder, tells agents which project that is, and lets you set one font on all the text of a scene or of the whole video.

- **One font for many text clips.** A lyric caption is one text clip per line, so changing the Font of one clip left the others in the old font. A text clip's settings now have two buttons under Font: **Use for this scene** sets the font on every text clip that overlaps the scene the selected clip is in, and **Use for all text** sets it on every text clip, titles and lyric captions alike. Undo takes the change back. A clip that is alone in its scene, or lies outside every scene, tells you so and nothing changes. The Font select itself still changes only the selected clip, and Overlays > Font for text and captions still applies only to new text and to captions you add afterwards.
- **Project name bar.** A bar labeled PROJECT with the open project's name sits above the Builder's toolbar, so you can see which project you are in. Point at it to see the full path. A project that agents cannot find (not saved yet, or outside a project folder the app lists) shows "Agents cannot see this project".
- **Agents know the open project.** The app tells an agent which project its window has open when the agent connects through MCP, and the agent can ask again with the `api_get_app_open_project` tool (`GET /api/v1/app/open-project`). "This project" now has an answer. Only a saved project in a project folder the app lists counts. The report is not listed as agent activity.

Installed 0.1.13 offers this update itself: Menu, Check for Updates. Nothing installs without your click, or while a job is running. New installs: download `H3-Studio_0.1.14_x64-setup.exe` for Windows, or `H3-Studio_0.1.14_amd64.AppImage` or `H3-Studio_0.1.14_amd64.deb` for Linux below.
