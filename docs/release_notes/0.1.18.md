H3 Studio 0.1.18 makes the Pass 2 LoRA presets and unfinished drafts work with newer MiniMax H3 Turbo LoRA releases.

- **The 4 step and 8 step buttons find the current Turbo LoRAs.** They answered "No matching LoRA installed" for releases such as `minimax_h3_fl2v_turbo_4step_v1.3_768p_comfyui_bf16.safetensors` because they only knew the file names of older releases. They now match by family and step count and pick the newest version, using the family made for the mode (ref2v for reference, fl2v for image to video), a full LoRA over LightX2V, and skipping original-format files that do not load in ComfyUI.
- **Finishing a draft works after a Turbo LoRA update.** A draft remembers the Turbo LoRA it was made with, so finishing one after that file was replaced by a newer release failed with `Node 207: LoraLoaderModelOnly | Value not in list`. Finishing now uses the newest installed LoRA of the same family, kind and step count, so pass 2 keeps its step count.
- **Download link.** "Download MiniMax Turbo LoRAs" opens https://huggingface.co/lightx2v/Minimax-h3-Turbo/tree/main, which also appears in the MiniMax H3 model downloads.

Installed 0.1.17 offers this update itself: Menu, Check for Updates. Nothing installs without your click, or while a job is running. New installs: download `H3-Studio_0.1.18_x64-setup.exe` for Windows, or `H3-Studio_0.1.18_amd64.AppImage` or `H3-Studio_0.1.18_amd64.deb` for Linux below.
