H3 Studio 0.1.32 installs models for you, takes a Hugging Face token, restarts ComfyUI from the Builder, and installs the VRGDG nodes itself when your ComfyUI does not have the pack.

- **Install models from the Models dialog.** The MiniMax H3, Image Models and LLM Models tabs list 69 files, each with a check box. Install Recommended downloads the files the Builder uses by default, Install Selected downloads the ticked ones, and every file goes into the folder ComfyUI reads it from (`diffusion_models`, `text_encoders`, `vae`, `loras`, `latent_upscale_models` or `models/LLM`). Each download shows its progress and can be cancelled, a finished file is checked before it gets its name, a file you already have is never replaced, and installed files show as Installed.
- **Hugging Face token.** Menu, App Settings has a Hugging Face token field with Test, and the Models dialog has the same box at the top of its install tabs. With a token the installer fetches the files Hugging Face keeps behind a login, such as the Flux/Klein 9B diffusion model. Accept the model's licence on its page with the same account first. The token is saved in a file of its own next to the config, is never shown again and goes only to huggingface.co, never along a redirect to another server.
- **Restart ComfyUI button.** It sits next to the engine badge at the top right of the Builder. It asks first and says how many running or queued jobs a restart would lose, asks ComfyUI-Manager to restart ComfyUI, and waits until ComfyUI answers again. It needs ComfyUI-Manager with a security level of normal or lower, and says so when it cannot restart ComfyUI.
- **Install Missing Nodes.** When the VRGDG pack is not installed in ComfyUI, the Custom Nodes window used to ask the pack to install the nodes, and ComfyUI answered 404 or 405. H3 Studio now installs them itself with ComfyUI-Manager's command line, finds ComfyUI's Python (`python_embeded`, `.venv` or `venv`), runs one install at a time and shows which pack is installing, how many are done and the last line the Manager printed. Failures come back together instead of stopping at the first. The nvidia-vfx card installs the optional RTX Video Super Resolution library with pip from NVIDIA's index.

The pack has the same Models tabs, token box and Restart button since pack 10.0.9: update it in ComfyUI-Manager and restart ComfyUI. They work in H3 Studio with or without the pack. A resumed download and a free disk space check are not in the app yet.

Installed 0.1.31 offers this update itself: Menu, Check for Updates. Nothing installs without your click, or while a job is running. New installs: download `H3-Studio_0.1.32_x64-setup.exe` for Windows, or `H3-Studio_0.1.32_amd64.AppImage` or `H3-Studio_0.1.32_amd64.deb` for Linux below.
